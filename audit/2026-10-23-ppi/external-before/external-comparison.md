# External regression oracle and SPM construction probe

Run on 2026-10-23. The fixture contains only deterministic synthetic data. The frozen source copy used for the R export is `/tmp/multippi-oracle-src-1RYCrM`; SHA-256 of `R/ppi_design.R` is `9d51f87f77cb17d2843ec579748de5ca436387fc513ee5a1eae59e14ee2b2177` and of `R/ppi_fit.R` is `cb840c671d15d0d5552946d410a40e368f31654d3440555130c8bd0861f3afa2`. These identify the tested pre-grouped-noise snapshot; they do not qualify any later edits. R 4.5.1, multiPPI 0.1.0 and fmriAR 0.4.2 produced the saved input and result fixtures.

The [validation scripts and four synthetic fixtures](../../inst/validation/external_ppi/) exercise a two-run design with separate run coefficients and compare the exported design against Nilearn 0.14.1 `OLSModel`/`ARModel`, NumPy 2.5.4 and SciPy 1.18.1. They check coefficients, residual variance, coefficient standard errors, named condition A-minus-B (equally across runs) estimate, standard error and t, and the two-condition F. The script independently verifies condition contrast mapping and estimability. It checks IID, four censored scans with IID fitting, a duplicated design column with estimable contrasts, and a fixed AR(1) coefficient 0.42. [Machine-readable errors](external-nilearn-results.json) retain all values. Maximum absolute errors across metrics were IID 8.53e-14, censored IID 3.15e-14, rank deficient 1.11e-14, and fixed AR 2.84e-14, below 2e-8. The censor fixture was fit using observed rows in each implementation. The estimator comparison is conditioned on the exported design: **it does not validate how either the neural seed or interaction columns were constructed**, nor estimated-noise inference.

For the rank-deficient example, Nilearn 0.14.1 `OLSModel.fit` computes dispersion with `n - number_of_columns`, whereas this comparison uses `n - rank`. Nilearn's own unadjusted dispersion differed by up to 0.012951; rank-corrected dispersion computed from its residuals was passed explicitly to Nilearn's contrast methods. Thus the reported rank-deficient t/F agreement is conditional on that external correction, not a claim that Nilearn's default rank-deficient result agrees. Aliased coefficient estimates are deliberately excluded from direct coefficient comparison and their nonestimability is independently checked.

Nilearn's `ARModel.whiten` leaves each first row unchanged. The fixed fmriAR plan uses exact AR(1) first-row scaling `sqrt(1 - phi^2)` at each run start. The oracle applies Nilearn's filter separately to each run, adjusts its first row, then fits with Nilearn `OLSModel`. Omitting the boundary correction changes the fitted coefficients by up to 0.0165753 in this fixture; the two default boundary conventions must not be treated as equivalent. Official implementation references: [Nilearn regression source](https://github.com/nilearn/nilearn/blob/0.14.1/nilearn/glm/regression.py), [Nilearn contrast source](https://github.com/nilearn/nilearn/blob/0.14.1/nilearn/glm/model.py), and [fmriAR source](https://github.com/bbuchsbaum/fmriAR).

## Actual SPM construction comparison

The real `spm_peb_ppi.m` from official SPM commit `54dc957191112dcad116e3eaa457e881fa8260de` was executed under GNU Octave 11.1.0 with synthetic `SPM` and `xY` structs and `showGraphics=0`. Its SHA-256 is `c28b73ca3e166ea065099bb0fc05a45969c22e1ba3400c8078cdff715b201615`. We retrieved the specific official dependencies, including the required matlabbatch classes, into `/tmp/multippi-spm`: 305 `.m` files totaling 934,183 bytes, all checked against the pinned tree's Git blob IDs and separately [hashed](external-spm-function-hashes.txt). The actual routine completed, produced `PPI_synthetic.mat`, and exported [synthetic PPI vectors and HRF](../../inst/validation/external_ppi/fixtures/) using the [probe](../../inst/validation/external_ppi/spm_octave_probe.m); the [execution receipt](external-spm-octave.log) records `SPM_PPI_SUCCESS 40`. Octave printed an `execution_exception` shutdown message despite exit status zero and a saved, readable result; it did not prevent calculation. No algorithm stubs or source patches were used. The absence of an Octave graphics toolkit did not prevent this `showGraphics=0` run.

The [comparison script](../../inst/validation/external_ppi/compare_spm.R) uses the same 40-scan raw physiological series, SPM-detrended task input, SPM HRF, TR=1, microtime=1 and sampling offset 0 in the frozen multiPPI construction. The task-convolution maximum absolute difference is **7.63e-17**. SPM removes the physiological mean; after matching that centering, the maximum difference is **4.44e-16**. For the neural seed the maximum absolute difference is **1.2640**, RMSE **0.2242**, correlation **0.9475**. For the interaction, raw maximum absolute difference is **0.09844**, RMSE **0.03203**, correlation **0.99899**; after centering the multiPPI interaction to match SPM's final detrending, maximum absolute difference is **0.08165** and RMSE **0.02727**. All metrics are retained in [the machine-readable receipt](external-spm-comparison.json). These are descriptive differences on one deliberately bounded synthetic specimen, not a numerical-equivalence or scientific-accuracy claim.

Important construction choices differ: SPM uses PEB deconvolution with its own covariance priors, a DCT basis padded by 128 samples, detrending of the neural seed and final interaction, and its `T0` sampling. The frozen multiPPI construction uses unpadded DCT ridge with lambda 0.1 and 40 basis functions; its neural seed is not centered and its convolution is a causal Riemann sum. The chosen scan-aligned microtime removes sampling-grid ambiguity for this example but does not equate the inverse problems. [SPM's PPI manual](https://github.com/spm/spm-docs/blob/main/docs/manual/ppi/ppi.md) and the [actual pinned function](https://github.com/spm/spm/blob/54dc957191112dcad116e3eaa457e881fa8260de/spm_peb_ppi.m) describe its construction.
